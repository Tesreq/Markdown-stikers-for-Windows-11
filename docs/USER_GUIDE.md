# Использование StickyDesk

Установите StickyDesk через [установщик](INSTALLATION.md) и запустите из меню «Пуск». На рабочем столе появятся заметки, в области уведомлений — значок приложения. Если значок скрыт, раскройте дополнительные значки около часов.

## Заметки

- Создать: меню значка в трее или `···` на стикере → «Создать стикер».
- Подключить файл: меню значка в трее → «Открыть Markdown-файл…». Исходный файл остаётся в своём каталоге.
- Открыть каталог: `···` → «Открыть папку».
- Изменить цвет: `···` → «Цвет».
- Закрыть заметку: `···` → «Закрыть заметку» или Alt+F4. Текст сохраняется, файл остаётся в папке. Чтобы открыть её снова, выберите файл через «Открыть Markdown-файл…» в трее. Название и цвет сохраняются.
- Удалить заметку: `···` → «Удалить заметку…» → подтвердить. Файл перемещается в Корзину, стикер убирается. Для подключённого внешнего файла удаляется именно файл по пути из подтверждения. Текущий текст стикера, включая несохранённые изменения, остаётся в `recovery/<id>.md`.

Если файл уже отсутствует, «Удалить заметку…» убирает оставшийся стикер и сохраняет копию текста. После удаления всех заметок они не создаются заново при следующем запуске; новую можно добавить через трей.

Стикер перемещается за свободную полоску сверху, размер меняется за нижний правый угол. Окна других приложений перекрывают стикеры.

В меню стикера пять действий: создать стикер, выбрать цвет, открыть папку, закрыть заметку и удалить её. Скрыть все стикеры или выйти из приложения можно через значок в трее.

## Название и Markdown

Крупное название находится внутри заметки. Один клик позволяет его изменить; Enter сохраняет, Esc отменяет. Вместе с названием переименовывается Markdown-файл в той же папке: «Рабочие планы» → `Рабочие планы.md`. Это работает и для подключённых внешних файлов. Основной текст и формат файла сохраняются. Линия под названием отделяет основной текст.

Если имя занято или недопустимо для Windows, приложение объяснит ошибку и оставит прежнее название. Для удалённого файла меняется путь будущего восстановления; сам файл появится после команды «Восстановить файл».

Клик по основному тексту или «Править» открывает исходник. «Готово», Esc или уход из редактора возвращают оформление. F2 включает редактирование. Ctrl+клик по ссылке открывает её в браузере или почтовой программе.

Поддерживаются заголовки, жирный текст, курсив, зачёркивание, списки, цитаты, чек-листы, ссылки и код. Чек-листы пока меняются через `- [ ]` и `- [x]`. Картинки показываются подписью, HTML — текстом; табличная раскладка не реализована.

Текст сохраняется после паузы 700 мс, при уходе из редактора и выходе. Доступны стандартные Ctrl+C/V/X/Z/Y/A и Ctrl+S. Переключение режимов не меняет файл и не сбрасывает историю отмены.

## Конфликты и недоступный файл

Если файл изменён другой программой и в стикере есть несохранённый текст, появляется красный статус «Конфликт версий». Нажмите на него. Можно загрузить внешнюю версию, записать версию стикера, сохранить её в отдельный файл или решить позже.

Если файл удалён или перемещён, стикер остаётся с текстом. Нажмите красный статус «Файл удалён · восстановить…», чтобы открыть действия:

- «Восстановить файл» — создать Markdown-файл по прежнему пути из текущего текста стикера. Если файл уже появился, он не перезаписывается.
- «Выбрать другое расположение…» — подключить перемещённый файл; при различии текстов появится выбор версии.
- «Сохранить копию…» — сохранить текст в другом файле.
- «Проверить доступность снова» — перечитать прежний путь, например после возврата файла из Корзины.

Текст удалённой заметки сохраняется в `recovery/` и возвращается в стикер после перезапуска. Сам файл автоматически не создаётся. Если удалена и его папка, выберите другое расположение или сохраните копию. При ошибке записи текст остаётся в памяти; выход с несохранёнными изменениями требует подтверждения.

Если выбранный файл уже содержит текст стикера, конфликт не возникает. При редактировании конфликтующей заметки до совпадения с файлом статус снимается автоматически, и автосохранение возобновляется. Намеренно очищенный текст также сохраняется в копии восстановления и защищён при возврате другого содержимого из Корзины.

## Каталог данных и удаление приложения

По умолчанию используется `%LOCALAPPDATA%\StickyDesk`:

```text
config.json       заметки, заголовки, координаты и настройки
config.json.bak   предыдущая конфигурация
notes/            заметки, созданные приложением
recovery/         несохранённый текст и текст удалённых заметок
logs/errors.log   ошибки и диагностика
```

При записи рядом с изменяемым файлом создаётся `.bak` с предыдущей версией. Файлы должны быть в UTF-8; сохраняются BOM и основной тип перевода строк.

Автозапуск включается через настройки в трее. При переносе EXE выключите и включите автозапуск заново. Установленную программу можно удалить через список приложений Windows после выхода из трея; данные сохраняются. Переносную версию удаляют вместе с её папкой, предварительно выключив автозапуск.

Для отдельного набора заметок можно указать другой каталог данных:

```powershell
.\StickyDesk.exe --data-dir "C:\Мои заметки\StickyDesk"
```
