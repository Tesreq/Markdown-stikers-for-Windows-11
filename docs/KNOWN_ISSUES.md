# Известные ограничения

- Привязка стикеров зависит от внутренней структуры окон Explorer. На другой сборке Windows может понадобиться изменение интеграции. При ошибке приложение сообщает о ней через трей; TopMost не используется.
- При сохранении существующего Markdown-файла Windows блокирует конкурентную запись и удаление на время проверки хеша и записи. Файл записывается через тот же открытый дескриптор; дополнительно сверяется идентификатор файла. Перед изменением сохраняются `.bak` и журнал с исходными и новыми байтами. Это проверено на локальной файловой системе Windows; сетевые папки и программы синхронизации отдельно не проверены.
- Для сохранения нужны права на изменение самого файла и создание журнала и резервной копии в его каталоге. При отказе записи текст остаётся в стикере и копии восстановления.
- После аварии неоднозначная версия на диске не перезаписывается автоматически. Новый текст показывается в стикере для выбора версии, а исходные и новые байты остаются в архиве журнала. При повреждённом UTF-8 можно сохранить восстановленный текст отдельной копией. Сбои питания, накопителя и исчерпание свободного места ещё требуют отдельной приёмки.
- Восстановление содержит текст с момента последней попытки сохранения. Последние символы перед аварийным завершением могут не попасть в копию.
- Поддерживается UTF-8. Смешанные переводы строк после редактирования приводятся к основному типу.
- Чекбоксы отображаются, но пока не переключаются кликом. Картинки не загружаются, HTML показывается текстом, таблицы не имеют табличной раскладки.
- Ссылки открываются через Ctrl+клик для http, https и mailto.

- Установщик и приложение пока не подписаны сертификатом издателя.

Непроверенные сценарии перечислены в [TESTING.md](TESTING.md). Версия 0.3.2 ещё не прошла полную приёмку по ТЗ.
