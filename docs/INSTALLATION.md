# Установка StickyDesk

[Скачать установщик StickyDesk 0.3.4](https://github.com/Tesreq/Markdown-stikers-for-Windows-11/releases/download/v0.3.4/StickyDesk-Setup-0.3.4-x64.exe). Версия использует прозрачные пиксели углов на современном рабочем столе Windows 11 и обрабатывает временный отказ прозрачности без необработанного исключения. Последние заметки в трее и удаление без подтверждения сохранены. Нужна Windows 11 x64.

Для запуска без установки скачайте [переносную версию ZIP](https://github.com/Tesreq/Markdown-stikers-for-Windows-11/releases/download/v0.3.4/StickyDesk-Portable-0.3.4-x64.zip), распакуйте её и запустите `StickyDesk.exe`. В архиве также находится уведомление о лицензии Markdig. В локальной рабочей копии готовые EXE находятся в корне проекта.

Закройте StickyDesk через трей и запустите установщик. Права администратора и установленный .NET не нужны. Программа устанавливается в `%LOCALAPPDATA%\Programs\StickyDesk`; ярлык появится в меню «Пуск». Ярлык на рабочем столе можно выбрать при установке.

Существующие заметки подхватываются из `%LOCALAPPDATA%\StickyDesk`. Для обновления запустите новый установщик после выхода из приложения. Удаление через список приложений Windows сохраняет заметки, настройки и внешние Markdown-файлы.

Дистрибутив пока не подписан сертификатом издателя.

## Сборка и проверка

```powershell
.\scripts\setup-installer-tools.ps1
.\scripts\installer.ps1
.\scripts\test-installer.ps1
```

Подготовка компилятора требует сети: фиксированный [Inno Setup 7.1.1](https://jrsoftware.org/inno-setup/downloads) скачивается с официального источника и проверяется по SHA-256 и подписи Pyrsys B.V. Компилятор работает из `.local/tools` в переносном режиме. Можно передать собственный Inno Setup 7 через `-CompilerPath`.

После полной очистки проекта компилятор и NuGet-кэш нужно восстановить заново. `installer.ps1 -Offline` используется только при заполненном кэше зависимостей.

Исходник установщика — `installer/StickyDesk.iss`, генератор иконки — `scripts/create-icon.ps1`. Пакет содержит только автономный EXE и уведомления о лицензиях. Результат сборки сохраняется одним EXE в корне проекта.

Проверка выполняет установку, запуск с тестовыми данными, обновление и удаление в отдельной папке `.local/installer-tests`. Существующая установленная копия блокирует этот тест. Для версии 0.3.4 прошли все 11 проверок установщика и 135 проверок приложения.
