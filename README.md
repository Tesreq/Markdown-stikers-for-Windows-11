# StickyDesk

Markdown-стикеры для рабочего стола Windows 11. C# · .NET 10 · Windows Forms · Win32 API.

## Запуск

Установщик в корне проекта: **[StickyDesk-Setup-0.3.2-x64.exe](StickyDesk-Setup-0.3.2-x64.exe)**.

[Установка и удаление](docs/INSTALLATION.md)

Заметки остаются на уровне рабочего стола. Управление — через меню `···` и значок в трее. Текст сохраняется автоматически; приложение работает локально. Автономной сборке не нужны Visual Studio или установленный .NET.

Возможности: Markdown-просмотр и редактирование, отдельное крупное название, перемещение и размер, пять цветов, подключение внешних `.md`, обработка конфликтов, восстановление сессии и автозапуск по выбору пользователя.

[Инструкция пользователя](docs/USER_GUIDE.md) · [Ограничения](docs/KNOWN_ISSUES.md)

## Структура

```text
src/
  StickyDesk.App/           Windows-приложение
    Application/           управление заметками и файловыми сессиями
    Desktop/               интеграция с Explorer и Win32
    UI/                    стикер, трей, контролы и диалоги
  StickyDesk.Core/          логика без зависимости от WinForms
    Models/                конфигурация и модели
    Storage/               чтение, сохранение и конфликты файлов
    Markdown/              Markdown → RTF

tests/                     консольные и нативные проверки
tools/                     диагностика окон рабочего стола
scripts/                   сборка, тестирование, публикация и очистка
installer/                 исходник установщика Windows
docs/                      актуальная документация
samples/                   пример заметки и конфигурации
StickyDesk-Setup-*.exe     актуальный самостоятельный установщик
.local/                    кэш, тестовые данные, диагностика и резервные копии
```

## Разработка

Нужны Windows и .NET 10 SDK. Из корня проекта:

```powershell
.\scripts\build.ps1
.\scripts\test.ps1
.\scripts\publish.ps1
```

При заполненном локальном кэше добавьте `-Offline`. Скрипт публикации не перезаписывает EXE работающего приложения. Очистка `bin`/`obj`: `scripts/clean.ps1`; полная очистка временных файлов: `scripts/clean.ps1 -AllGenerated`. Предварительный просмотр — с `-WhatIf`. После полной очистки первая сборка восстанавливает зависимости из сети.

[Команды разработки](docs/DEVELOPMENT.md) · [Архитектура](docs/ARCHITECTURE.md) · [Проверки](docs/TESTING.md)

## Данные и зависимости

Рабочие заметки и настройки: `%LOCALAPPDATA%\StickyDesk`. Внешние Markdown-файлы остаются на своих местах. `.local` содержит только локальные материалы разработки и сохранённые копии; каталог исключён из Git.

Версия приложения — **0.3.2**. Запись защищена от одновременной перезаписи другим процессом; незавершённые сохранения и переименования имеют журнал восстановления. Для разбора Markdown используется Markdig 1.6.0; браузерного движка нет. Лицензия зависимости: [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt).

Исходники сохранены в локальном Git-репозитории. Пользовательские заметки, резервные копии, кэши и готовый установщик в историю не входят. Удалённый репозиторий не настроен.
